# 🌲 CampingTN – Camping Discovery Platform

## 📌 Project Overview
CampingTN is a web-based platform designed to help users discover, explore, and manage camping locations in Tunisia and worldwide.  
The goal of the project is to simplify outdoor tourism by connecting campers with camping site owners through a modern and easy-to-use interface.

---

## 🎯 Objectives
- Provide a global catalog of camping sites 🌍  
- Allow users to search and explore camping locations 🔎  
- Enable camping owners to publish their camping spots 🏕️  
- Improve tourism accessibility in Tunisia 🇹🇳  
- Offer a simple and responsive user experience 💻📱  

---

## ⚙️ Features

### 👤 User Features
- User registration and login
- Browse available camping locations
- View detailed camping information (price, location, description)
- Search and filter campsites
- Contact or book camping spots

### 🏕️ Owner Features
- Add new camping locations
- Edit or delete existing listings
- Manage camping availability

### 🛠️ Admin Features (if applicable)
- Manage users
- Approve or reject camping listings
- Monitor platform activity
